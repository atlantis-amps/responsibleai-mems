# Contributing to #responsibleai-mems

Thank you for your interest in contributing to responsibleai-mems! We welcome contributions from everyone. Following these guidelines helps ensure a smooth and respectful collaboration process for all maintainers and contributors.

------------------------------------------------------------------------

## 📜 Code of Conduct

By participating in this project, you agree to abide by our [Code of Conduct](CODE_OF_CONDUCT.md). Please report any unacceptable behavior to hmorzaria\@hotmail.com.

------------------------------------------------------------------------

## 🐛 How to Report a Bug

If you find a bug or unexpected behavior, please check the [Issues](https://github.com/atlantis-amps/responsibleai-mems/issues) tab to ensure it hasn't already been reported.

If it is a new bug, please open a new issue and include: \* **Clear title:** A brief, descriptive summary of the issue. \* **Steps to reproduce:** Step-by-step instructions to recreate the bug. \* **Expected vs Actual behavior:** What should have happened vs what actually happened. \* **Environment details:** Your operating system, language/framework versions, and browser (if applicable).

------------------------------------------------------------------------

##💡 How to Suggest a Feature

We love new ideas! To suggest a feature, open an issue using our Feature Request template (if available) or create a blank issue. Please explain: \* **The problem:** What gap or issue does this feature solve? \* **The solution:** A clear description of what you want to happen. \* **Alternatives:** Any alternative solutions or workarounds you have considered.

------------------------------------------------------------------------

## 💻 How to Submit Changes (Pull Requests)

Please follow this Git workflow to propose changes to the codebase:

### 1. Fork and Clone

- [Fork the repository](https://docs.github.com/articles/fork-a-repo) to your own GitHub account.

- Clone your fork locally:

  ``` bash
  git clone https://github.com/atlantis-amps/responsibleai-mems
  ```

### 2. Create a Branch

- Create a localized branch for your changes. Use a descriptive name:

  ``` bash
  git checkout -b feature/your-feature-name
  # OR
  git checkout -b fix/bug-description
  ```

### 3. Make Changes and Test

- Implement your code or documentation updates.
- Ensure your changes adhere to our coding styles (see below).
- Run existing tests and add new tests if applicable to ensure nothing breaks.

### 4. Commit and Push

- Write clear, descriptive commit messages:

  ``` bash
  git commit -m "Fix: Resolve visual clipping issue on mobile views"
  ```

- Push the branch to your GitHub fork:

  ``` bash
  git push origin feature/your-feature-name
  ```

### 5. Open a Pull Request (PR)

- Go to the original repository on GitHub and click **Compare & pull request**.
- Fill out the PR template with a clear description of your changes.
- Link the PR to any related open issues (e.g., `Closes #12`).
